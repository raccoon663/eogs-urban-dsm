# Data access

This repository does not include WorldView-3 imagery, RPC metadata, the reference DSM, semantic labels, or the original dataset archive.

## Official source

The experiment used the EOGS `dataset_v01` release:

- EOGS repository: <https://github.com/mezzelfo/EOGS>
- Release archive: <https://github.com/mezzelfo/EOGS/releases/download/dataset_v01/data.zip>
- Underlying benchmark: DFC2019/US3D Jacksonville

Users are responsible for checking the current dataset terms and obtaining any required access. Do not commit or redistribute the raw WorldView-3 crops or other restricted source data.

## Expected local structure

After running `python scripts/prepare_data.py --scene JAX_004`, the ignored local data directory should contain:

```text
data/
├── images/JAX_004/          # pan-sharpened multi-view image crops
├── rpcs/JAX_004/            # RPC JSON metadata
├── truth/JAX_004/
│   ├── JAX_004_DSM.tif      # LiDAR-derived reference DSM
│   ├── JAX_004_DSM.txt      # grid metadata
│   └── JAX_004_CLS.tif      # semantic labels
├── affine_models/JAX_004/   # generated by to_affine.py
└── ablation/{4,8,full}/     # generated by select_views.py
```

The packaged source data used by the experiments were 665–814 pixels wide and 697–827 pixels high. The evaluation grid is 512 × 512 at 0.5 m in EPSG:32617. The exact reference vertical datum and LiDAR acquisition date remain **UNKNOWN / NOT VERIFIED**.

## Files needed to reproduce

The source imagery, RPC JSON files, reference DSM, grid metadata, and semantic labels must be downloaded or copied under valid authorization. Generated affine cameras and view subsets can be recreated from those inputs with the included scripts. None of these source rasters are tracked by Git.
